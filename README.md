# Course_work_Selfstudy_project

## Описание:

Course_work_Self-study_project - это платформа для самообучения студентов.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/Course_work_Selfstudy_project
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

#### После этапа "Установка" запустите проект командой "python manage.py runserver" и теперь Вам доступен функционал.

## Доступный функционал:



##### Действия с разделами обучения:

Эти дейстивия доступны только пользователям находящимся в группах Teacher и Admin:
* Создание
* Просмотр
* Редактирование
* Обновление
* Удаление


##### Действия с материалами обучения(уроками):

Эти дейстивия доступны пользователям находящимся в группах Teacher и Admin:
* Создание
* Просмотр
* Редактирование
* Обновление
* Удаление

Просмотр и проходжение теста доступно пользователям группы Student.
