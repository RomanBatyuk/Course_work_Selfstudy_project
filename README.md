# Course_work_Selfstudy_project

## Описание:

Course_work_Self-study_project - это платформа для самообучения студентов.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/RomanBatyuk/Course_work_Selfstudy_project
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

## Доступный функционал:

##### Действия с разделами обучения:
* Создание
* Просмотр
* Редактирование
* Обновление
* Удаление

##### Действия с материалами обучения:
* Создание
* Просмотр
* Редактирование
* Обновление
* Удаление
